# Changelog

Este projeto usa versionamento de demonstração para deixar claro o estado publicado no portfólio.

## v1.1.0-demo — 2026-08-06

- Produto renomeado para **Catálogo Operacional de Compras** em toda a experiência pública.
- README reorganizado para destacar uso diário, busca operacional, integridade e limites reais.
- Interface, metadados e ícone atualizados para a nova identidade.
- Adicionada validação automática contra o retorno do nome antigo em superfícies públicas.
- Mantidos FastAPI, índice SQLite/FTS5, backup, OCR opcional e controle de concorrência por revisão.

## v1.0.0-demo — 2026-07-16

- Primeira publicação sanitizada, então chamada **ProcureFlow**, com massa de dados fictícia.
- Interface de busca, cadastro técnico e tratamento de conflito documentados com capturas reais.
- API FastAPI local, índice SQLite/FTS5, backup e controle de revisão incluídos na demonstração.
- Testes de contrato, validação da interface estática e GitHub Actions configurados.
