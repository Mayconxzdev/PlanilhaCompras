# Avisos de terceiros

Este repositório inclui cópias distribuídas das bibliotecas abaixo para permitir uma demonstração sem etapa de build.

| Biblioteca | Uso | Licença |
| --- | --- | --- |
| [fflate](https://github.com/101arrowz/fflate) | Leitura e escrita de arquivos compactados usados na importação/exportação | MIT |
| [html5-qrcode](https://github.com/mebjas/html5-qrcode) | Leitura de QR/código de barras por câmera | Apache-2.0 |

Electron fez parte da evolução original do produto, mas não é distribuído nesta demonstração web. O código de produto publicado aqui foi revisado para não incluir dados operacionais, credenciais, artefatos de instalação ou arquivos de terceiros sem necessidade.
